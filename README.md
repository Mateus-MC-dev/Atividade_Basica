# Atividade\_Basica

Este repositório foi desenvolvido como parte de uma atividade acadêmica para praticar o ciclo básico de versionamento de código utilizando Git e GitHub. O objetivo principal é simular um ambiente de trabalho em equipe, aplicando comandos essenciais como clonagem de repositórios, criação de branches locais, commits organizados e envio de alterações (push) de forma colaborativa.
